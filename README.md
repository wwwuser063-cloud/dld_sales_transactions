Dubai Land Department (DLD) Sales Transactions Analysis


Project Overview

This project presents an in-depth exploratory data analysis and interactive visualization of the Dubai real estate market based on Dubai Land Department (DLD) sales transaction records. The goal is to uncover yearly market trends, top-performing areas, property type distributions, pricing dynamics (Price per Square Foot), and transaction volumes across Ready and Off-Plan properties.

Key Features & Insights

- Total Sales & Transactions: Analyzed multi-billion AED market volumes and total transaction counts across various years.
- Yearly Sales Trend: Illustrated exponential growth and market recovery trajectories from 2015 to 2025.
- Top 10 Areas: Highlighted high performing zones such as Marsa Dubai, Burj Khalifa, and Business Bay by total sales volume.
- Property Type Breakdown: Evaluated transaction distributions across Units(Apartments), Villas, Lands, and Buildings.
- Price Analysis (PSF): Examined average Price per Square Foot categorized by room buckets.
- Registration Type Split: Compared Ready properties against Off-Plan market shares.


Tools & Technologies Used

- Data Source: Kaggle (dld_sales_transactions)
- Data Processing & Cleaning: Python, Jupyter Notebook, Pandas, Numpy
- Data Visualization & Dashboard: Power BI
- Version Control: Git & GitHub
